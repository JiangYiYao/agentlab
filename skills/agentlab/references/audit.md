# 审查评分

觉得分数不合理、怀疑裁判提示词或想比较前后口径时，从 `report.md` 里该分数旁的「审计」链接开始。链接会定位到 `runs/<run_id>/audit.html` 中的对应记录，用浏览器打开即可，不需要启动服务或联网。

使用 Skill 时，agent 会在汇报结果时主动提供当次报告和审计页链接，并说明发现的异常。你不需要自己查找实验目录；可以直接让它解释某个分数、检查裁判提示词或比较前后评分，由它查阅记录并给出依据。

`run`、`rescore` 生成报告时会一起生成审计页。旧实验可以重新生成：

```text
<py> <skill-dir>/scripts/cli.py report --exp <实验目录> --run <run_id>
```

这只读取归档并生成页面，不执行被测命令、不调用裁判，也不改变历史分数。

## 从一个分数查起

1. **先看来源。** 页面分别标明执行是否复用、该关注点本轮是否评分。换了裁判后，同一次试验可能是 LLM 分重新评、脚本分仍复用。原始评分来源有记录时会给出 run ID；旧记录无法追溯时明确标为未知。
2. **核对任务与标准。** 查看归档任务、本轮关注点与通过条件、裁判实际使用的标准。复用分数时，旧裁判使用的标准与本轮通过阈值可能不同，应分别检查。
3. **看完整输入。** `stdin.md` 是 AgentLab 交给裁判命令的内容，即使命令实际用 argv 或文件接收提示词，也保留这份文本。`prompt.md` 通常只是任务，不能代替完整输入。重点检查评价目标是否偏离任务、是否夹带了领域假设、标准是否遗漏或互相冲突。
4. **核对材料。** 清单区分已提供、缺失、截断，链接到保存的文件。确认关键回答、结构化产物或文件改动确实在材料里。并排评审还可查看匿名答卷与版本的对应关系。
5. **把原话与解析结果对上。** 原始 stdout/stderr、调用记录与最终分数放在同一条记录中。检查命令是否失败、回复是否完整、解析值是否符合原话，以及证据是否足以支撑判断。裁判只给分数或空 `evidence` 时，不能替它补理由。
6. **对比前一次。** 有明确重评来源时与该次比较，否则与此前最近一次同名试验、同一关注点比较。差异包含任务、标准、完整输入、调用配置、stdout、文件改动、证据清单、脚本 JSON 输出和解析分数。不同执行的差异只用于追溯变化，不能单凭它断定改分由哪一处引起。

页面可按版本、用例或关注点搜索，也能按原始 `pass` 或 unknown 筛选。原始 `pass` 是测量结果中的字段，可能为空或来自裁判回复；最终是否满足要求，还取决于通过条件和跨试验统计。页面会展示已保存的版本汇总判定，并链接到 `promotion.json`。内置测量和系统检查没有裁判提示词，阅读配置和分数证据即可。

## 原始文件

| 评估方式 | 当前运行内的目录 |
|---|---|
| 独立裁判 | `trials/<trial_id>/outputs/judges/<concern_id>/` |
| 并排裁判 | `compare/<case_id>__<cell_id>__r<repeat>/` |
| 脚本评分 | `trials/<trial_id>/outputs/evaluators/<concern_id>/` |

以上目录均相对于 `runs/<run_id>/`。调用记录为 `execution.json`，完整进程输出为 `stdout.log`、`stderr.log`。新记录会保留超时前已写出的输出；启动失败时日志可能为空。脚本另存 `result.json`（脚本解析值），JSON 评分还会保存读取到的 `output.json`。试验分数以 `scores.json` 为准，最终晋级判定见运行目录中的 `promotion.json`。

页面每段文本最多预览 128 KiB，超出会明确标记，并可打开原文件查看全部内容。文本对比使用相同预览范围，不把未显示部分视为相同。每份材料清单最多展示 300 项，完整清单仍可查看。页面是便于阅读的派生文件，原始材料继续使用共享归档；清理工作区和缓存后仍能审计。搬迁时应保留整棵实验目录。

## 记录的边界

- 页面保存的是 AgentLab 提供的输入。外部 CLI 追加的系统提示词、历史会话和服务端上下文没有完整捕获。
- 命令记录说明请求的配置，不独立证明实际使用了哪个模型。
- 文件出现在评审目录，不证明模型实际读取或理解了它；需要更强验证时，应由外部执行器提供可审计的访问或工具调用记录。
- 调用记录不完整保存宿主环境或外部脚本依赖，不能单凭它保证在另一台机器上完全重现。
- 旧记录没有的输入、日志或来源会标明缺失，不用当前配置拼出一份貌似完整的历史。生成页面也不会自动补跑评分。
